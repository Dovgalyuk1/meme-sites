# meme-sites

Серия статических одностраничников под мем-коины. Один сайт = одна папка.
Каждая папка деплоится отдельным проектом на Vercel с `Root Directory` = имя папки.

```
meme-sites/
├── <coin-name>/          # сайт: index.html + assets/ + README.md
├── claude/               # разборы сайтов (идея, механика, ссылки)
├── tools/                # вырезание персонажа, проверка через Playwright, деплой
└── CLAUDE.md             # как работать в этом репозитории
```

Стек: чистый HTML/CSS/JS без сборки. Никаких зависимостей, никакого билд-шага.
