# meme-sites

Серия статических одностраничников под мем-коины. Один сайт = одна папка.
Каждая папка деплоится отдельным проектом на Vercel с `Root Directory` = имя папки.

```
meme-sites/
├── <coin-name>/          # сайт: index.html + assets/ + README.md
├── claude/               # разборы сайтов (идея, механика, ссылки)
├── tools/                # вырезание персонажа, проверка через Playwright, деплой
├── .claude/              # разрешения и хук окружения для Claude Code
└── CLAUDE.md             # как работать в этом репозитории
```

Стек: чистый HTML/CSS/JS без сборки. Никаких зависимостей, никакого билд-шага.

## Как запустить работу

Открыть Claude Code на репозитории `Dovgalyuk1/meme-sites` (окружение `Default`) и
прислать картинку с тикером. Дальше по шагам из `CLAUDE.md`: сайт собирается в новой
папке, проверяется Playwright-ом, пушится в `main` и поднимается на Vercel одной
командой `tools/vercel.sh new <имя>`. Правки готового сайта выкатываются на `git push`
сами, примерно за 30 секунд.
