# Папка на рабочем столе, связанная с GitHub

Задача: Олег кидает картинки в папку у себя на маке, а Claude в облаке их видит.
Решение — обычный клон этого репозитория, лежащий на рабочем столе. Папка та же,
файлы те же, просто она умеет отдавать своё содержимое в GitHub.

## Разовая настройка

1. Поставить **GitHub Desktop**: <https://desktop.github.com>. Войти своим
   аккаунтом `Dovgalyuk1` — он же заведёт доступ к репозиторию, пароли и токены
   вручную нигде вводить не надо.
2. **File → Clone repository → Dovgalyuk1/meme-sites**, в поле Local path
   выбрать рабочий стол. Появится папка `~/Desktop/meme-sites` — это и есть
   общая папка.
3. Внутри уже лежат папки сайтов. Исходники каждого сайта — в
   `<имя-сайта>/assets/src/`. Для текущего это `gloobert/assets/src/`.

## Как этим пользоваться

Кидаешь картинки в `<имя-сайта>/assets/src/`. Имена любые. Для нового сайта
папку можно просто создать руками, название = будущий адрес.

Дальше одно из двух:

- **GitHub Desktop.** Открыть, увидеть свои файлы в списке, нажать
  `Commit to main`, затем `Push origin`. Две кнопки.
- **Двойной клик по `tools/mac-sync/push-src.command`.** Скрипт сам найдёт новые
  файлы в `assets/src`, закоммитит и отправит. Откроется окно терминала с
  отчётом, закрывается любой клавишей.

После этого написать в чат, что картинки на месте. Claude сделает
`git pull`, нарежет их `tools/panels.py --auto` и выкатит сайт.

## Что скрипт не делает

- Не трогает ничего, кроме путей `*/assets/src/*`. Рабочие файлы, черновики и
  всё остальное в папке остаются только у тебя.
- Ничего не удаляет.
- Не ставится в автозапуск и не висит в фоне. Запускается по двойному клику,
  делает дело и закрывается.

Первый запуск macOS может ругнуться, что файл скачан из интернета: правый клик
по файлу → Open → Open. Дальше открывается обычным двойным кликом.
