# Работа в этом репозитории

Дизайн, копирайтинг, механики мини-игр, архетипы, вырезание персонажа и правила
Олега — в личном скилле `meme-coin-site-builder`, он подгружается автоматически.
**Этот файл переопределяет только раздел «Деплой» скилла**: там описана схема для
Cowork (device_bash на маке + Chrome), здесь среда другая и всё делается из облака.

## Раскладка

Один сайт = одна папка в корне. Внутри `index.html` (инлайновые `<style>` и
`<script>`), `assets/`, `README.md`. Папка `claude/` — разборы, `tools/` — утилиты.
Ветка по умолчанию `main`.

Имя папки = имя Vercel-проекта = поддомен `<имя>.vercel.app`. Выбирай его сразу и
больше не меняй: переименование проекта в Vercel домен само не создаёт.

## Git — прямо из облака

В этой среде пуш работает из сессии, `~/.ghtok.json` и device flow не нужны.
Токен уже в `$GITHUB_TOKEN`, автор коммитов подставляется сам.

```bash
git add -A && git commit -m "add <имя>: <что>" && git push -u origin main
```

Новый сайт — это новая папка и обычный коммит. **Создавать репозитории из сессии
нельзя** (403, токен привязан к подключённым репозиториям), поэтому всё живёт здесь,
и отдельный репозиторий на сайт больше не делаем.

## Что доставить в контейнер

Playwright и Chromium уже стоят (`/opt/node22/lib/node_modules/playwright`,
`/opt/pw-browsers/chromium`). Для `tools/cutout.py` один раз за сессию:

```bash
pip3 install --quiet numpy pillow
```

## Проверка перед деплоем (обязательна)

```bash
cd <имя> && (nohup python3 -m http.server 8901 >/dev/null 2>&1 &)
node tools/check.js <имя>          # из корня репозитория
```

Скрипт гоняет Playwright: ловит `pageerror`, снимает hero/игру/секции на 1440 px,
проверяет мобилку 390 px на горизонтальный скролл. Что смотреть глазами: игра
проходится до 8/8, персонаж нигде не обрезан, кропы целые.

## Vercel — через API, своим токеном

Нужны `VERCEL_TOKEN` в переменных окружения и `api.vercel.com` в сетевом allowlist
окружения. Если `curl api.vercel.com` даёт 403 от прокси — сеть ещё не открыта,
это не повод молчать: скажи Олегу одной строкой, что именно закрыто.

Деплой нового сайта — `tools/vercel.sh`: создаёт проект с `rootDirectory=<имя>`,
привязывает его к этому репозиторию, ждёт сборку, печатает живой адрес.
Правки существующего сайта деплоятся сами на `git push`, ничего вызывать не надо.

Перед созданием проекта проверь, что `<имя>.vercel.app` свободен: 404 NOT_FOUND
значит свободен. Если занят — Vercel молча выдаст суффикс вроде `имя-nu.vercel.app`
и не предупредит.

Домен Олег покупает сам. Привязка купленного домена к проекту и DNS-записи — тоже
через API, `tools/vercel.sh domain <имя> <домен>`.

## Чего не делать

- Не трогать чужие папки при работе над своим сайтом.
- Не вводить за Олега пароли, коды и платёжные данные, не покупать домены.
- Не коммитить токены. `VERCEL_TOKEN` живёт только в переменных окружения.
