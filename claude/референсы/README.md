# Библиотека референсов

Сюда складывается всё, что Олег присылает как образец. Один набор = один файл
разбора. `snapshots/` — копии исходного HTML на случай, если сайт снимут с
хостинга; ассеты не сохраняем, только страница.

## Как разобрать новый референс

```bash
node tools/ref.js https://сайт.fun/          # снапшот + структура в консоль
node tools/ref.js https://сайт.fun/ имя      # если имя файла нужно своё
node tools/ref.js claude/референсы/snapshots/имя.html   # перечитать снапшот
```

Инструмент печатает палитру, шрифты, разметку, ассеты, брейкпоинты, сигналы JS
и все видимые тексты. Дальше разбор пишется руками в файл набора по шаблону:
приём · как сделан · когда брать · чего в нём не хватает.

После разбора: строка в таблицу ниже, при необходимости правка канона в
`CLAUDE.md`, коммит в `main`.
