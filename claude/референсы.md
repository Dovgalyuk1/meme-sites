# Референсы — как Олег их присылает и что с ними делать

Олег регулярно кидает чужие сайты как примеры того, что хочет получить.
Разборы этих сайтов — память серии: каждая новая сессия начинается с нуля,
поэтому всё, что мы поняли про референс, должно лежать здесь файлом.

## Как прислать сайт

**Ссылкой — основной способ.** Олег кидает адрес, Claude сам его читает.
Требует одной разовой настройки окружения, см. ниже.

**Файлом.** На сайте Cmd+S, тип «Веб-страница, только HTML», файл в чат или
сразу в `claude/inbox/`. Сайты жанра — один HTML с инлайновыми стилями и
скриптами, так что в файле есть всё, кроме картинок.

**Скриншотами.** Прямо в чат. Кода в них нет, но композиция, палитра и
типографика видны — этого хватает для «сделай в таком духе».

Лучше всего пара: файл плюс два-три скриншота.

## Разовая настройка: открыть сеть окружению

Без неё ссылки не читаются — прокси режет чужие домены с 403.

На claude.ai/code над полем ввода есть кнопка с облаком и именем окружения
(`Default`). Нажать → навести на окружение в списке → шестерёнка справа →
в диалоге поле **Network access**.

Дальше один из двух вариантов:

- **Full** — любой домен. Самое простое: после этого любая присланная ссылка
  читается, настраивать больше нечего. Поле со списком доменов при выборе
  Full пропадает — так и должно быть, список не нужен, Vercel и всё
  остальное попадают под «любой домен».
- **Custom** — свой список, по домену в строке. Тогда к тому, что там уже
  есть, дописать `*.fun`, `*.wtf`, `*.com`. Ведущая `*.` покрывает все
  поддомены. Галочку «Also include default list of common package managers»
  оставить как стояла.

  Если возвращаешься на Custom с Full, список придётся набрать заново.
  Обязательный минимум под деплой: `api.vercel.com` и `*.vercel.app`.

Настройка применится к новым сессиям, текущую надо перезапустить.

## Что делает Claude

```bash
node tools/refs.js                      # всё из claude/inbox/ и tools/refs.txt
node tools/refs.js kapy.wtf             # конкретный домен
node tools/refs.js claude/inbox/x.html  # сохранённая страница
```

Скрипт кладёт в `claude/refs/<имя>/`:

| файл | что внутри |
|---|---|
| `desk.png`, `mob.png` | скриншоты 1440 и 390, полной высотой |
| `facts.json` | вес, шрифты, палитра, заголовки, кнопки, весь текст, соцсети |
| `разбор.md` | болванка разбора с заполненной машинной частью |
| `mirror/` | локальная копия сайта, в гит не идёт |

Дальше Claude **смотрит скриншоты глазами** и дописывает `разбор.md`:
что это за персонаж, какой архетип, какая мини-игра и на сколько шагов,
чем держится оформление, как звучит копирайтинг, что забрать себе и что
не повторять. Машина размечает факты, разбор пишет человек.

`battlegroundcat.fun` не известно ничего.
