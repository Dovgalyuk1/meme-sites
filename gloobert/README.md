# gloobert · $GLOOB

Одностраничник мем-коина GLOOBERT. Чистый статический HTML/CSS/JS, без сборки.
Поддомен: `gloobert.vercel.app` (имя папки = имя проекта Vercel = поддомен).

Персонаж: низкополигональный рыжий кот с огромными глазами, который постоянно
оказывается в новых ситуациях и сам не знает как. Голос текстов — первое лицо,
строчные, сухая констатация абсурда.

## Что где

```
gloobert/
├── index.html          весь сайт: инлайновые <style> и <script>
├── assets/
│   ├── og.png          1200×630, превью для X и телеграма
│   └── favicon.png     256×256, он же apple-touch-icon
└── README.md
```

Персонаж и все восемь сцен нарисованы вектором прямо в `index.html`
(`<g id="glArt">` + `<use>`), поэтому растровых ассетов всего два. Кропы в
секции FIELD NOTES — это `viewBox`-окна по той же фигуре, не отдельные файлы.

## Как включить контракт и ссылки

Блок SETTINGS — первый скрипт в `<head>`, больше нигде ничего менять не надо:

```js
window.CONTRACT = "";   // адрес контракта; пусто = в чипе CA стоит soon
window.TWITTER  = "";   // ссылка на X
window.BUY_URL  = "";   // прямая ссылка на покупку
```

Логика кнопки BUY: есть `BUY_URL` — ведёт туда; пусто, но есть `CONTRACT` —
ведёт на `ponsfamily.com/launchpad/<CA>`; нет ничего — кнопка серая и не
кликается. С заполненным `CONTRACT` чип CA копируется по клику, кнопка CHART
уходит на dexscreener, а блок цифр внизу подтягивает живые данные из
DEXScreener API. Без контракта там честная надпись `CHART GOES LIVE ON LAUNCH`.

## Механика

`THE SHUFFLE` — реальность роняет Глуберта в случайную ситуацию, игрок водит
картонной коробкой по низу кадра. Восемь пойманных = восемь открытых карточек
в секции `WHERE HE HAS BEEN`. Мышь, палец и стрелки клавиатуры. Промахи только
пишутся в ленту событий и ничего не блокируют.

Звук и музыка — Web Audio, ни одного аудиофайла: ленивый лаунж-мьюзак на 5/4 и
отдельный тон на каждое событие. Кнопки SOUND и MUSIC в шапке. Музыка стартует
после гейта и глушится, когда вкладка уходит в фон.

Клик по коту в первом экране сыплет монеты и звенит.

## Проверка

```bash
cd gloobert && (nohup python3 -m http.server 8901 >/dev/null 2>&1 &)
node tools/check.js gloobert          # из корня репозитория
```

Проверено: ошибок страницы нет, на 390 px горизонтального скролла нет, игра
проходится до 8/8, персонаж нигде не обрезан. `api.dexscreener.com` из
контейнера закрыт — блок живых данных проверяется только в проде.
