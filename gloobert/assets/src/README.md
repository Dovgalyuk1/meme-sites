# Сюда кладутся исходники от Олега

Оригинальные рендеры этого сайта: контактная сетка ситуаций и персонаж на
однотонном фоне. Форматы любые: png, jpg, webp. Имена любые, но если написать
`grid` и `char` — разбор пойдёт без вопросов.

```bash
python3 tools/panels.py gloobert --auto
```

Команда сама найдёт здесь сетку и персонажа, нарежет `assets/pan-01…12.webp`
и вырежет `assets/cut.webp`. Файлы в этой папке остаются как есть — это
оригиналы, из них всегда можно перерезать заново.
